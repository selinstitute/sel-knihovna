# SEL Library

**Referenční slovník pojmů sociálně-emočního učení**

Knihovna pojmů sociálně-emočního učení (SEL), psychologie a příbuzných oborů v češtině.
Vydává **SEL Institute, z. s.** Projekt vede Libor Webster.

Každé heslo popisuje, co pojem tvrdí, kdo ho formuloval a kdy, co je z něj doložené, co je
sporné a kým, co prakticky funguje bez ohledu na spor a kde se s ním člověk běžně setká.
Každé faktické tvrzení má dohledatelný zdroj.

**Jak hesla vznikají:** píše a kontroluje je AI linka a každou revizi nezávisle ověřuje
samostatná kontrola (sel-qa). U hesla je uvedeno, kdo ho ověřil a kdy, a jak silně je pojem
doložený.

**Verze 2026.11** (2026-11-09): 102 hesel. Na webu: https://selinstitute.cz/knihovna/

## Obsah repa

- `hesla/`: hesla v Markdownu s hlavičkou YAML (název, definice, opora, zdroje, historie revizí).
- `sel-knihovna.ttl`: celá knihovna jako slovník SKOS (Turtle).
- `CITATION.cff`, `.zenodo.json`: metadata pro citaci a archivaci na Zenodu.

## Jak citovat

Citujte verzi knihovny (DOI) a adresu konkrétního hesla na webu, například:

> SEL Institute, z. s. (2026). *SEL Library: referenční slovník pojmů sociálně-emočního učení* (verze 2026.11). Zenodo. DOI viz Zenodo
